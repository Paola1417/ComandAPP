# ComandAPP Smart Recommendations

Prueba de concepto independiente para un sistema de recomendación de productos para ComandAPP.

## Objetivo
Demostrar que, a partir de productos que aparecen juntos en pedidos, se pueden generar recomendaciones de productos.

## Estructura del proyecto

```
diruptiva/
├── backend/     # API REST con Node.js y Express
├── data/        # Datos de prueba y modelo de recomendación
└── frontend/    # Interfaz de usuario React
```

## Tecnologías
- Node.js y npm
- Express (backend)
- React (frontend)
- Datos de prueba en formato JSON

## Nota importante
Este proyecto es INDEPENDIENTE y no está conectado con:
- La APK ComandAPP existente
- El proyecto web principal
- El backend principal de ComandAPP
